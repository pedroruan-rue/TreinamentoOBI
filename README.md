# Treinamento OBI e Programação Competitiva
Repositório contendo minhas resoluções de problemas algorítmicos desenvolvidas durante a participação em um grupo de treinamento focado na Olimpíada Brasileira de Informática (OBI). 

As soluções documentadas aqui foram implementadas em **Python**, priorizando código limpo, aplicação de lógica matemática e otimização de tempo de execução.

## 📚 Trilhas de Estudo e Paradigmas
Os algoritmos estão separados pelos tópicos exigidos no treinamento:
* Problemas Ad Hoc (simulações e lógica geral)
* Técnicas de Pré-processamento
* Recursão e manipulação em nível de bits (Bitwise)

## 🛠️ Tecnologias e Conceitos Aplicados
* Python 3
* Estruturas de Dados e Algoritmos
* Análise de Complexidade de Tempo e Espaço (Big-O)
